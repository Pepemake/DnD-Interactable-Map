# DnD Interactable Map

## Current Functionalities

### Interactive World Map

* Displays a custom world map using Leaflet.
* Supports very large image maps.
* Smooth zooming and panning.
* Custom dark-themed UI.
* Multiple map layers.

---

## Map Layers

Current supported layers:

* Base Map
* Borders Map
* Geography Map

Layers can be switched instantly through the left-side control panel.

---

## Marker System

### Quest Markers

* Add quests directly onto the map.
* Custom quest icon.
* Editable quest title.
* Editable notes / quest descriptions.
* Drag-and-drop positioning.
* Complete quests.
* Abandon quests.
* Delete quests.

### Settlement Markers

* Add permanent settlements.
* Custom settlement icon.
* Editable settlement title.
* Editable settlement notes.
* Drag-and-drop positioning.
* Delete settlements.

---

## Quest Tracking System

### Active Quests

* Shows all active quests currently on the map.
* Clicking a quest displays its notes.

### Completed Quests

* Quests moved here when completed.
* Preserves quest information.

### Abandoned Quests

* Quests moved here when abandoned.
* Preserves quest information.

---

## UI Features

* Large scalable UI.
* Dark fantasy themed interface.
* Large readable text.
* Popup editing system.
* Separate left and right side control panels.
